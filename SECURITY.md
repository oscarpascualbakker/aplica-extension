# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Email **security@aplica.cv** with:

- what you found and where,
- the steps to reproduce it,
- the browser and extension version you used.

Please do not include real personal data in your report. We will acknowledge your message
and keep you informed until the problem is fixed. Please give us reasonable time to fix it
before disclosing it publicly.

## Supported versions

Only the latest published version of the extension receives security fixes.

## Scope

This repository contains the Aplica browser extension. Problems in the Aplica web app or
its API (`aplica.cv`) can be reported to the same address.
